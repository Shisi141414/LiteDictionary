# 词条格式规范

本规范适用于本知识库全部词条的撰写与修订。

## JSONL 行格式

每行一个 JSON 对象，字段：

```json
{"term": "中文名|English Name", "aliases": ["别名"], "definition_brief": "**定义**：……。\n**性质**：……。", "definition_detail": "结构化正文（见下）", "tags": ["学科", "子主题", "类型"]}
```

## definition_brief 结构化格式

```
**定义**：核心定义（含主公式）。
**性质**：要点1；要点2；要点3。
```

- 两段之间以 `\n` 分段（JSON 中写作 `\n`）；总长 100~220 字符；
- "定义""性质"加粗；性质为 2~4 个要点以分号串联（**不编号**，保持紧凑）；
- 公式使用 LaTeX（`$..$`，反斜杠双写）。

## definition_detail 结构化格式

内部按 `\n` 分段（JSON 中换行写作 `\n`）：

```
概念名：
**定义**：……（核心定义+判据/公式，公式用 LaTeX）
**性质**：
1. ……；
2. ……；
3. ……。
```

规则：

1. **段落**：第一行「概念名：」，随后「**定义**：」，再「**性质**：」（定义、性质二字加粗）。人物/事件/单一事实类词条没有性质段可不写，定义写完自然结束。
2. **性质用有序列表**：多条性质/分类/要点写成 `1. …；\n2. …；\n3. …。` 每条换行，末条分号、最后一条句号。
3. **定义段多条时用无序列表**：一个概念有多个定义角度/层次/流派界定时写成 `- …；\n- …。` 每条换行（`- ` 开头加空格）。
4. **公式优先**：凡是能用公式、符号、反应式、表格表达的一律用 `$..$`（LaTeX），文字只做串联。目标：detail 正文 200～400 字，公式/符号占一半以上。
5. **常用记法**：幂/根/分式用 LaTeX（$x^2$、$\\sqrt{2}$、$\\frac{a}{b}$）；化学式用 $\\mathrm{H_2SO_4}$；单位 $\\mathrm{kJ/mol}$；强调用 **加粗**。
6. 性质条数不限（1～6 条），按重要性排序；每条尽量一行内闭合。

## 人物词条模板

```
**人物中文全名**（English Name，生卒年），国籍（历史国名可注今属），身份头衔。
* **主要成果**：……；
* **主要著作**：《……》（年份）、……；
* **主要荣誉与影响**：……。
```

- 首行：**粗体中文全名** + 括号内英文名与生卒年（如 1818-1883）+ 国籍 + 身份定位
- 三条固定无序列表（`* ` 开头，每条 \n 换行，末条句号）：主要成果 / 主要著作 / 主要荣誉与影响，标签加粗；
- 人物词条 tags 类型为"人物"，子主题用"人物志"；
- 跨学科人物按侧重分别入库（例：经济学库的马克思侧重《资本论》，哲学库侧重唯物史观），首行定位语注明侧重。

## LaTeX 转义

- JSON 字符串中 LaTeX 反斜杠双写：`\\frac{a}{b}`
- 换行是单反斜杠 + n：`\n`
- 行内公式 `$..$`，独立公式 `$$..$$`；`$` 个数必须成偶数
- 字符串内禁用未转义双引号

## 其他字段

- `term`：`中文|English` 竖线分隔，英文用标准教科书译名
- `aliases`：JSON 数组（别名/缩写/常见误写），可为 `[]`
- `tags`：`[学科名, 子主题, 类型]`，类型 ∈ {概念, 定律, 定理, 公式, 方法, 模型, 人物, 实验, 反应}
